# Fuentes — ABC Areal Semi-Mono / ABC Areal

Copia aquí los archivos licenciados con **exactamente** estos nombres
(el orden recomendado es `.woff2`, pero también valen `.otf` / `.ttf` con el mismo nombre base):

| Archivo                              | Uso                          |
| ------------------------------------ | ---------------------------- |
| `ABCArealSemiMono-Regular.woff2`     | texto general (400)          |
| `ABCArealSemiMono-Bold.woff2`        | TulS / footer / énfasis (700)|
| `ABCAreal-Regular.woff2`             | variante Normal (400)        |
| `ABCAreal-Bold.woff2`                | variante Normal bold (700)   |

Si tus archivos se llaman distinto, edita las rutas de `@font-face` en `../styles.css`.
Si usas `.otf` o `.ttf`, no hace falta tocar el CSS: `@font-face` ya contempla esas extensiones con el mismo nombre base.

Si tu licencia no permite publicar los archivos, no los subas al repositorio:
sirve la fuente desde un origen externo y actualiza las rutas de `@font-face`.
